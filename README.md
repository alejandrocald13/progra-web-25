# Homework 2 — Interfaz de selección de perfiles

Esta tarea es una interfaz sencilla hecha con HTML y CSS, inspirada en plataforma de streaming como Netflix. Muestra una selección de perfiles con imágenes y nombres, permitiendo al usuario elegir quién está viendo.

## 🖼️ Vista general

La interfaz incluye:
- Un encabezado centrado con la pregunta: **"Who is watching now?"**
- Una fila de imágenes de perfil con nombres debajo
- Un botón en el pie de página que dice **"Manage Profiles"**
